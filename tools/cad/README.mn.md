# DWG/DXF → 3D прототип

[improvements-and-3d.mn.md](../../docs/improvements-and-3d.mn.md)-ийн §4 B урсгал ба §7 алхам 1-ийн прототип:
давхрын DXF зураг → барилгын glTF (GLB) загвар + нэгжийн `units.json` → нэгжийг төлөвөөр өнгөлсөн web viewer.
Viewer ба жишээ өгөгдөл `landing/3d/`-д байх тул нүүр хуудастай хамт e-property.mn/3d/ дээр нийтлэгдэнэ.

## CAD давхаргын стандарт (хөгжүүлэгчид өгөх)

Нэг DXF = нэг стандарт давхрын төлөвлөлт, нэгж нь метрээр.

| Давхарга | Объект | Утга |
|---|---|---|
| `EP-UNIT` | Хаалттай LWPOLYLINE | Нэгжийн хил. Хэмжилтийн аргыг (ханын дотор тал гэх мэт) гэрээнд заана |
| `EP-UNIT-ID` | TEXT, хилийн дотор | Давхар доторх нэгжийн дугаар: `01`, `02` … |
| `EP-UNIT-AREA` | TEXT, хилийн дотор | Зарласан талбай, м²: `64.3` |
| `EP-CORE` | Хаалттай LWPOLYLINE | Шат, лифт, коридор — зөвхөн дүрслэл |

Бусад давхарга (хана, хаалга, тавилга) уншигдахгүй тул зургаас устгах шаардлагагүй.
Нэгжийн ID нь `<блок>-<давхар 2 оронтой><дугаар>` хэлбэртэй: B блокийн 3-р давхрын 04 = `B-0304`.

## Ажиллуулах

```sh
python3 -m venv .venv && .venv/bin/pip install -r tools/cad/requirements.txt
cd tools/cad
../../.venv/bin/python demo_projects.py      # 3 жишээ төсөл → landing/3d/data
../../.venv/bin/python test_dxf2glb.py       # self-check
cd ../../landing && python3 -m http.server 8765   # → http://127.0.0.1:8765/ ба /3d/
```

DWG-г эхлээд ODA File Converter-ээр DXF болгоно. `dxf2glb.py` нь нэгж бүрийн `area_measured`-ийг хилээс
тооцож, зарласан талбайтай `--tolerance` (анхдагч 2%)-оос илүү зөрвөл `area_flag` тавина. Шошгогүй буюу хоёр
шошготой хил бол `PROBLEM:` мөр хэвлэж 1 кодоор гарна.

Viewer-т `?project=central-tower&unit=A-1905` нь тухайн нэгжийн паспортыг шууд нээнэ.

Нэг зургийг гараар хөрвүүлэх бол:
`../../.venv/bin/python dxf2glb.py plan.dxf --block B --floors 3-16 --height 3.0 --out out/my-project`

Бүгд зохиомол, viewer-т `Жишээ мэдээлэл` гэж тэмдэглэгдэнэ. м² үнийн суурь нь 2026 оны 2-р сарын шинэ орон
сууцны дундаж (Global Property Guide): Хан-Уул 4.64 сая ₮, Сүхбаатар 6.25 сая ₮, хотын дундаж 4.76 сая ₮
(Баянзүрхийн тоо нийтлэгдээгүй тул). Давхар дээшлэх тусам 0.6%-иар өснө.

| Төсөл | Хэлбэр | Давхар | Нэгж |
|---|---|---|---|
| Туулын Эрэг, B блок (Хан-Уул) | Коридортой хавтгай блок, Г хэлбэрийн нэгжтэй; 06 нэгж талбайн зөрүүтэй | 3–16 | 84 |
| Төв Цамхаг, A блок (Сүхбаатар) | 26 м дөрвөлжин цамхаг, төв цөм, Г хэлбэрийн 4 өрөө + студи | 3–22 | 120 |
| Өглөөний Гэгээ, C блок (Баянзүрх) | Г хэлбэрийн дунд давхрын блок, хоёр жигүүр | 2–9 | 88 |

## Нэгжийн дотор зураг (бүтэцтэй төлөвлөлт)

Нэг DXF = нэг нэгжийн төрөл, координат нь барилгын plan.dxf-тэй ижил хүрээнд байна.
`node tools/cad/plan-dxf.mjs import plan.dxf --id <төсөл>/<төрөл> --revision <хувилбар>` →
`plans/<төрөл>.plan.json` (schema: [docs/apartment-plan.mn.md](../../docs/apartment-plan.mn.md)).
Импортлогч Node дээр ажилладаг (Python шаардлагагүй). Алдаатай бол 1 кодоор гарна.

| Давхарга | Объект | Утга |
|---|---|---|
| `EP-UNIT` | Хаалттай полилайн | Нэгжийн гадна хил (plan.dxf-тэй ижил) |
| `EP-UNIT-AREA` | TEXT | Зарласан талбай, м² |
| `EP-WALL-<EXT\|PARTY\|CORR\|INT>-<зузаан мм>-<өндөр мм>` | LINE эсвэл нээлттэй полилайн | Хананы тэнхлэг. Жишээ: `EP-WALL-INT-120-2700` |
| `EP-WIN-<доод мм>-<өндөр мм>` | LINE хананы тэнхлэг дээр | Цонхны өргөн |
| `EP-DOOR-<өндөр мм>-<L\|R>` | LINE: нугаснаас чөлөөт үзүүр рүү | Хаалга. L/R нь тухайн шугамын чиглэлээр харахад нээгдэх тал |
| `EP-ENTRY-<өндөр мм>-<L\|R>` | LINE | Орцны хаалга |
| `EP-OPEN-<өндөр мм>` | LINE | Хаалгагүй нүх |
| `EP-ROOM` | Хаалттай полилайн | Өрөө (хананы дотор нүүрээр) |
| `EP-ROOM-TAG` | TEXT өрөөн дотор | `төрөл\|нэр\|шал`, жишээ: `bedroom\|Унтлагын өрөө\|wood` |
| `EP-ZONE-KITCHEN`, `EP-ZONE-PLUMBING` | Хаалттай полилайн | Гал тогоо, сантехникийн тогтмол бүс |
| `EP-META` | TEXT `түлхүүр=утга` | `units=m\|cm\|mm`, `ceiling=2.7`, `north=<градус>`, `id=`, `revision=` |

Муруй хана (ARC, bulge) болон шошгогүй өрөөг алдаа гэж мэдээлнэ; автоматаар засахгүй. Растер болон PDF зургийг
таних боломж байхгүй. Ийм зургийг CAD дээр ул мөр болгон тавиад эдгээр давхаргаар гараар зурна.
Жишээ: `landing/3d/data/tuul-river/plans/type-01.dxf` (`plan-dxf.mjs export`-оор JSON-оос үүсгэсэн, жишээ төлөвлөлт).

## Хязгаар

- Бүх давхар ижил төлөвлөлттэй гэж үзнэ. Өөр төлөвлөлттэй давхарт тусад нь DXF хөрвүүлэх нь дараагийн алхам.
- Төлөв, үнэ, хүлээлтийн хугацаа нь `units.json`-д үүсгэсэн жишээ. Бүтээгдэхүүнд API-аас авна.
- `dxf2glb.py` хана, цонх, дотор засал загварчлахгүй; нэгжийн эзэлхүүн л гарна (L2). Нэгжийн дотор зураг нь дээрх `plan-dxf.mjs` урсгалаар (L3).
