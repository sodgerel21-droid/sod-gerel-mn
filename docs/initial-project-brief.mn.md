# E-Property — e-property.mn

Баригдаж буй үл хөдлөх хөрөнгийн төсөл, нэгж, захиалга, гэрээ, төлбөр болон эрхийн бүртгэлийн төлөвийг холбох платформ.

**Үндсэн уриа:** Үл хөдлөх хөрөнгө үүсэхээс өмчлөх хүртэл.

**Зорилтот домэйн:** `e-property.mn` — хэрэглэгчийн сонгосон домэйн. DNS, эзэмшил, хостинг, бодит нийтлэлт энэ шатанд шалгаагүй, хийгээгүй.

Энэ хавтас одоогоор бүтээгдэхүүний төлөвлөлтийн баримт агуулна. Ажиллах программ болон төрийн системийн бодит холболт хараахан үүсээгүй.
